## Домашнее задание 7. Мини-анкета

**Цель:** самостоятельно объединить несколько знакомых действий.

Напиши консольную анкету, которая спрашивает:

1.  Имя.
2.  Любимое занятие.
3.  Любимый город.

Сохрани каждый ответ в отдельную переменную типа string.

Затем выведи аккуратную анкету, например:

 ```text
--- Моя анкета ---
Имя: Миша
Любимое занятие: Игры
Любимый город: Казань
```

**Условия:** - три отдельных вопроса; - три отдельные переменные; - все
ответы получаются через Console.ReadLine(); - используй
интерполяцию; - оформи вывод несколькими строками.

## Домашнее задание 8. Консольная визитка

**Цель:** самостоятельно выполнить исходную задачу, объединив всё
изученное.

Напиши программу, которая:

1.  Спрашивает имя пользователя.
2.  Спрашивает его любимое занятие.
3.  Сохраняет ответы в переменные name и hobby.
4.  Выводит приветствие.
5.  Выводит любимое занятие пользователя.
6.  Выводит ещё одну фразу на своё усмотрение, используя обе переменные.

**Условия:** - не копируй готовое решение из предыдущих заданий; -
используй string, Console.ReadLine(), Console.WriteLine() и
интерполяцию; - программа должна корректно работать с разными введёнными
значениями.
